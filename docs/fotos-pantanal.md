# Fotos das fichas de espécies do Pantanal: para validar

Todas do Wikimedia Commons, com licença livre, hospedadas em `data/fotos/pantanal/` (1200×800, recorte 3:2). Autor, licença e link aparecem em cada ficha. Confirme se a espécie e a escolha estão boas; para trocar, edite `data/fotos/pantanal.json` (as fotos são indexadas pelo nome científico) e rode `python3 -I build/build.py` e `--publish`.
